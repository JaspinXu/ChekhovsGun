# README visuals

- `hero.png`: original conceptual illustration generated with the built-in imagegen tool. It is not a product screenshot.
- `architecture-zh.svg` / `architecture-en.svg`: editable, self-contained vector figures. Regenerate with `python scripts/render-readme-diagrams.py`.
- Palette: warm paper, navy, muted teal, amber. SVGs have an explicit background for consistent light/dark GitHub rendering, localized labels and accessible descriptions.

## Hero prompt

Use case: ads-marketing / editorial illustration.
Create a polished wide landscape GitHub README hero for the open-source project ChekhovsGun. Aspect ratio about 2.4:1, landscape, high resolution. This is conceptual artwork, not a screenshot.
Concept: the knowledge you saved comes back at exactly the right moment. On the left, a small sculptural library of layered article cards and video cards rests in a recessed archive tray. A graceful thin amber path threads through these saved fragments, carries one highlighted passage through the middle, and arrives in a beautiful minimal browser reading window on the right, where one small relevant saved-passage card glows subtly. Convey a quiet personal memory being reactivated, no robots or brains.
Visual style: premium editorial illustration, precise isometric paper objects, restrained tactile 3D with fine ink details, warm ivory background, deep midnight-navy typography, muted teal and amber accents, soft natural shadows, very generous whitespace. Sophisticated and calm, not cyberpunk or corporate stock art. Clean modular composition, beautiful at small README width. No excessive decorative particles, no neon gradients.
Text: top-left large perfectly spelled title "ChekhovsGun". Beneath it medium legible tagline "Your bookmarks. Right on cue." Bottom edge three small labels "SAVE"   "CONNECT"   "REDISCOVER", aligned to the narrative objects. No other words. The title and tagline must be prominent and readable. No numerical claims, star counts, benchmark results, logos from other products, weapons, or fake UI text.
Use most of the lower two-thirds for the visual story; keep every object contained within the frame with clean generous margins.
