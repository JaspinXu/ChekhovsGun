# 2026-09-18 优化与验证

## 取舍

梳理了扩展采集与提醒、纯 JS 检索核心、IndexedDB、offscreen 模型、Python
Engine / IngestPipeline / SQLite、平台适配器、CLI / 仪表盘和发布链路。
现有模块边界适合这个本地优先产品，本轮保留目录和检索参数，优先修复实际链路断点。

## 改动

- 补齐无 `source_id` 的页面身份，隔离页面冷却和缓存，扩展与 Python API 都排除当前收藏自身。
- 收藏夹扫描按身份跳过重复链接，避免分享参数不同导致标题存根覆盖正文；统计失败条目。
- service worker 启动后读取已保存的后端地址，主动搜索融合本地与后端结果；批量转发使用正确接口。
- 融合按稳定 ID 去重，保留大小写和远端来源信息；HTTP 原文链接保持可导航。
- 编码结果绑定实际签名，覆盖模型失败的首次查询和并发采集；模型加载代次防止关闭后被旧任务重新启用。
- 模型准备改用包含 ONNX 依赖的完整浏览器运行库，修复已下载模型仍无法加载的问题。
- 工具栏增加搜索、结果摘要和原文定位链接，包含空结果与失败反馈；修复隐藏扫描按钮被 CSS 显示的问题。
- CI 与 Release 使用同一打包逻辑，排除测试和已删除文件；保留原有 README 改动并校正架构说明。

## 验证

- JavaScript：136 个测试通过；新增回归先观察失败再修复。
- Python：258 个测试通过，Ruff 检查通过。
- 真实 Chromium 扩展：单条收藏搜索、正文定位链接、无后端运行、语义模型加载与
  384 维推理、神经编码采集与搜索、关闭模型后的 BM25 回退。
- 重新生成 Python / JavaScript 契约夹具，无差异；CLI demo 在隔离数据目录完成采集与检索。
- 带模型安装包构建成功（37 个文件，86.3 MB）；检查 ZIP 校验、manifest、模型和测试文件排除。
- 模型文件和浏览器测试 profile 位于忽略目录，没有纳入 Git。

## 边界

未使用个人站点凭据执行线上 YouTube / Bilibili 同步，也未验证每个站点当前 DOM。
收藏夹分页／虚拟列表并非都能被滚动扫描完整覆盖。纯跨语言查询仍可能被依赖词面覆盖率
的置信度阈值过滤；不能把“本地模型成功推理”等同于“跨语言召回质量已验证”。
后端转发是尽力而为，没有离线重试队列或双向同步。这些需要单独设计与数据集验证。
