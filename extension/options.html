ChekhovsGun 设置

收藏、索引和检索全部在这个浏览器里完成，不会把收藏和浏览记录发到任何别的地方。

模型跑在你自己的机器上，不联网。没装模型时扩展照常工作， 只是退化成关键词检索，中文问题就不容易命中英文收藏了。 安装方式见 npm run fetch-model。

本地 Python 服务（可选）

不开也完全能用。开了之后可以额外获得 Whisper 本地转写、 YouTube / B 站收藏夹批量同步——这些是浏览器做不到的。两边的检索结果会合并去重。

默认由 chekhovsgun serve 启动在 8700 端口。

收藏采集

这是「只需要收藏」的关键。关掉之后仍可以点扩展图标手动收。 部分网站用同一个按钮收藏和取消收藏，无法判断状态时会按「收藏」处理，多收的条目可以在 ChekhovsGun 里删除。

在哪些网站上启用

关掉某个网站后，ChekhovsGun 在那里既不提醒也不采集。

提醒行为

在冷却时间内重复刷到同一个视频不会再弹出。
